# 安卓新签名迁移

原签名密钥因开发电脑清理 `out` 丢失，无法再签署可覆盖旧版的 APK。
新安卓包使用 `com.crypticnotes.mobile.v2`，与旧版共存。

请从 Release 手动下载安装新包，不需要先卸载旧版。新包需要重新授权悬浮窗、
屏幕采集并设置偏好。旧版私有设置、小游戏存档和排行榜不能自动迁移；保留旧版
可以继续查看这些数据。两个版本不要同时启动识图。

新版“数据备份”支持用户选择文件导出、导入设置与小游戏本地记录。
它不能读取另一包名下旧版的数据，也不包含地图资源、安装包和录屏文件。

签名材料保存在开发者用户目录 `.jysj-signing`，不在项目或 `out` 中。
加密密钥另备份到外接盘。密码必须另外离线保存，不能只保留密钥文件。
发布脚本会先检查密钥位置、存在性和证书指纹，缺失时停止，不自动生成。
