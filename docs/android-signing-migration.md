# 安卓新签名迁移

原签名密钥因开发电脑清理 `out` 丢失，无法再签署可覆盖旧版的 APK。
新安卓包使用 `com.crypticnotes.mobile.v2`，与旧版共存。

请从 Release 手动下载安装新包，不需要先卸载旧版。新包需要重新授权悬浮窗、
屏幕采集并设置偏好。旧版私有设置、小游戏存档和排行榜不能自动迁移；保留旧版
可以继续查看这些数据。两个版本不要同时启动识图。

## 用电脑导出旧版数据（可选）

历史发布的 APK 开启了调试标记。若设备允许 USB 调试和 `run-as`，可在手机上
授权自己的电脑，然后使用 `scripts/export_android_legacy.py` 导出旧版数据。
这是数据导出，不能找回签名私钥。

1. 正常保存并退出旧版小游戏，停止识图；不要卸载旧版。
2. 在手机开发者选项打开 USB 调试，连接电脑并确认授权。
3. 电脑安装 Android platform-tools 与 Python，运行：

```powershell
python export_android_legacy.py --adb C:\platform-tools\adb.exe --output legacy-backup.json
```

4. 将 JSON 文件传到手机，在新版“数据备份 → 导入备份”中选择它。

脚本只读取旧应用，不停止进程、不卸载、不修改两套应用。设备限制或非调试版
会拒绝读取，此时保留旧版即可。备份包含设置及个人记录，请自行保管，勿公开上传。

新版“数据备份”支持用户选择文件导出、导入设置与小游戏本地记录。
它不能读取另一包名下旧版的数据，也不包含地图资源、安装包和录屏文件。

签名材料保存在开发者用户目录 `.jysj-signing`，不在项目或 `out` 中。
加密密钥另备份到外接盘。密码必须另外离线保存，不能只保留密钥文件。
发布脚本会先检查密钥位置、存在性和证书指纹，缺失时停止，不自动生成。
