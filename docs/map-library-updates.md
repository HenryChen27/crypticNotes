# 地图库更新与用户地图

Windows 更新器和 Android 的 APK 地图库同步使用同一套合并规则。

- 安装包的官方地图、登记信息和特征随版本更新。
- 用户新增地图及其登记、停用状态保留，活跃地图重建所需特征后继续参与识别。
- `official-library.json` 记录上一个官方版本的地图和文件，后续更新可以移除官方已撤回的地图，不会把用户新增地图当作旧官方地图清掉。
- 旧版没有来源记录，第一次迁移保留无法确认来源的条目。因而少量旧官方地图也可能保留，这是为了避免猜错来源后删除用户地图。
- 用户地图与新官方地图 ID 或源文件路径冲突时停止更新；请先在地图管理中备份、改名后重试。合并失败不替换正在使用的图库。
- Android 当前地图管理仍是只读，此修改保护应用数据目录中已有的自建地图，不新增手机录入界面。覆盖安装保留数据；卸载后重装无法保留应用私有数据。

## Windows 旧版首次过渡

旧版更新器会整目录替换地图库。仅发布新 EXE 不能改变正在运行的旧更新脚本。
已有自建地图的用户首次升级时，应先退出插件，备份整个 `maps` 文件夹，将新版
`scripts/update-client.ps1` 替换进原安装目录，再执行原更新入口。
此后使用新版更新器正常更新即可。不要直接把新包的 `maps` 覆盖进旧目录。

此改动尚未发布。macOS 手动替换整个应用包的迁移流程不在本次 Windows/Android 更新器修改范围内。
