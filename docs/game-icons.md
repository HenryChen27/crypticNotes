# 小游戏图标约定

每个游戏在 index.html 同级的 assets 目录放置 icon.png，即包内 game/assets/icon.png。建议使用 256×256 或 512×512 的正方形透明 PNG，文件小于 4 MiB，不需要为每个平台制作不同图片。

插件自动用于 Windows/macOS 游戏列表和布偶后台图标、安卓应用与悬浮球游戏列表及后台悬浮球。公共启动器同时读取这个文件作为 Windows 窗口/任务栏/托盘和 macOS Dock 图标。

优先使用已安装游戏包内的图标。现有三款游戏随插件提供一份图标，未下载也能显示。旧游戏缺少图标或文件无法解码时使用兼容图标，游戏仍可启动。小游戏合集打包脚本会自动把 assets/icon.png 导出为单独图标附件并写入目录的 icon 元数据。插件在后台同步列表时下载并校验这张小图，所以未下载游戏也能显示专属图标；不需要为每个新游戏修改插件代码。旧目录没有 icon 元数据时，安装后仍会自动读取包内图标。

资源包构建已包含 assets 下 PNG 文件，无需修改主入口代码。更新图标后要重新发布游戏资源包，客户端更新资源后生效。修改系统任务栏/Dock 的启动器逻辑需要同步更新公共启动器。
