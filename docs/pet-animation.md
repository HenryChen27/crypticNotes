# 布偶伙伴

设置中的「个性外观」开关控制布偶外观，关闭即恢复齿轮。拖动和点击操作不变，不影响识图、快捷键或叠图。提示直接显示在对话气泡中，没有角色名前缀。

布偶使用 `appearance/skins/doll/image.png` 的原始像素，运行时按多边形分成八层：头、身体、左右上臂、左右前臂、左右腿。原图不修改，不依赖外部动画软件或网络。

`rig.py` 的 `PARTS` 定义分层遮罩，`animation.py` 的 `pose()` 定义关节角度，`body_motion()` 定义根部位移与挤压。颈、肩、肘和髋有独立旋转中心；肘继承肩的变换。动作采用缓入、停留、缓出，结束回到原位。成功时双手收至胸口配爱心，失败时抬手甩臂跺脚配「!」，冲突或异常时挠头配「?」，交互时招手，隐藏时低头休息。

这是二维剪纸骨骼动画，不是三维模型或 Live2D 网格变形。原图只有一个角度，背面和被遮挡部位没有独立素材；大幅转身和精细手指动作不在当前能力内。替换原图时须同步调整遮罩和关节位置。

## 桌宠行为（`appearance/behavior.py`）

一个 1 Hz 的调度器 `PetBehavior`，只在没人看着它干活的时候动：匹配中、后台小游戏、设置面板打开、拖动中、叠图期间都不打扰。

- **小动作**：每 20–60 秒随机一个（歪头 `tilt`、换脚站 `shift`、伸懒腰 `stretch`、看向鼠标 `look`），省电模式间隔加倍，「安静模式」关闭。
- **打盹**：整机 5 分钟无输入（Windows `GetLastInputInfo`，macOS `CGEventSourceSecondsSinceLastEventType`）进入 `doze` 循环（呼吸变慢、低头），有输入或鼠标靠近时 `wake` 伸懒腰醒来；安静模式不打盹。
- **空闲淡出**：30 秒没碰布偶淡到七成，靠近恢复；可在设置关闭。
- **转头看气泡**：气泡在哪一侧，头就向那侧转 8°，气泡消失后回正；效果符号（爱心、「!」）改在另一侧冒出，不压住文字。
- **悬停招手**有 9 秒冷却，面板打开时不招手。

## 拖动与落地

被拖动时，躯干按鼠标速度反向倾斜，四肢像钟摆一样滞后摆动（弹簧跟随），手臂随提起略抬、整体上浮，脚下阴影缩小变淡；松手时播 `land`，一次压扁回弹。锁定位置后不可拖动，点击照常。摆幅与鼠标速度的增益是 60°/(px/ms)（上限 32°）：每帧挪 5 px 左右的慢拖（约 0.3 px/ms）就有十几度摆动，快一点就到上限；2026-11-07 之前增益只有 1.6，看起来像没做。

脚下常驻一个柔和椭圆阴影，随跳跃高度缩小变淡。

## 交互

- 单击立即打开设置面板；双击重新识别（会先收起刚打开的面板）；按下不再触发动作，松开时才抱一下。
- 右键是菜单：重新识别 / 隐藏（显示）叠图 / 小游戏 / 设置 / 退出。退出只在菜单里，不再是一次右键。
- 拖动时右上角出现一个红色半透明的「退出槽」（`ExitDropZone`，带门形图标和「拖到这里退出」字样）；指针进入槽内它亮起、标成「松开即退出」，桌宠做一下疑惑动作；**在槽内松手才退出**，拖出去再松手只是移动。不再按停留计时退出，手还按着时不会被动关掉（2026-11-08 改）。
- 识别中的旋转等待符号由各自皮肤提供（`skins/<皮肤>/waiting.png`，矿灯是蓝紫色带光晕的版本），位置按皮肤的 `WAITING_ANCHOR`；启动等待画面（`StartupPet`）也画同一个符号，并直接出现在上次保存的位置、沿用上次的桌宠大小，不再先在右上角闪一下再跳过去。
- 截图前不再隐藏桌宠：启动时用 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` 把桌宠窗口、气泡和退出槽标成「只显示在屏幕上、不进任何截图」（`windows.exclude_from_capture`，Windows 10 2004 起），整屏 BitBlt 也抓不到它们，所以无论走窗口截图还是整屏截图都不用藏；老系统设不上时才退回截图前短暂隐藏。从桌宠双击或面板发起识别时前台是我们自己的窗口，会改为按标题绑定游戏窗口。
- 单击桌宠先等一个系统双击间隔，确认不是双击后才同时做两件事：桌宠播 `heart`（布偶抱一下；矿灯先升空 170 px，到顶后才吐出鬼火，鬼火悬在镜片上方一点、灯旁 104 px 处燃烧，不再落到地面——面板正是在那里展开的）并打开设置面板。双击只做重新识别，不再触发 `heart`。`heart` 还在播放时（5 s）再点桌宠照常开关面板，但不重播（`DraggableGear.heart_playing`）。舞台窗口在设置面板打开时也保持显示（火悬在灯上方、激光在灯下渐隐，都不压到面板），不然单击开面板的同时就看不到火了；舞台上沿抬到地面以上 480 px。
- 隐藏叠图快捷键（默认退格）只在本次会话确实藏着一张叠图时才把它叫回来；平时按退格不再触发识图。
- 矿灯射激光时，激光与火花在灯眼以下按高度渐隐（舞台窗口上做 alpha 渐变遮罩），免得挡住正在看的地图；光束长度 `LASER_LENGTH` 由 280 缩到 170，射击时升空由 70 px 加到 120 px（舞台上沿相应抬到地面以上 330 px）。

## 设置（界面设置 → 布偶）

布偶大小 75%–150%、空闲淡出、安静模式、锁定位置。键分别是 `pet_scale`、`pet_fade`、`pet_quiet`、`pet_locked`。
「桌宠」一行切换身体：小布偶 / 磷焰矿灯，键是 `pet_skin`（`doll` / `lantern`），切换时保留大小、淡出和位置，启动动画也跟随这个选择。

## 第二只桌宠：磷焰矿灯（`appearance/lantern.py` + `skins/lantern/`）

原图 `skins/lantern/image.png`（444×484）按多边形拆成七层：灯体（顶盖、灯箱、底杆和右下的小晶簇）、提手（左右两根铁丝加顶环）、左侧垂下的链条、左右两簇冰晶、两条短腿。多边形沿铁丝边缘划分，提手转动时灯箱不会撕裂。
裂开的玻璃就是它的眼睛：光芒不是贴图，是在灯箱层上按状态实时画的——亮度（呼吸）、瞥视（亮核左右漂移）、眨眼（光熄灭一瞬）、眯眼（上下眼睑合成一道缝，上睑中间下压像皱眉，缝里额外加亮）。

它是悬浮的，靠飞行移动：待机离地约 36 px（画布单位，按钮里留了上方余量，`BASE_ORIGIN=(5,40)`、`BASE_SIZE=(112,146)`、`RENDER_SCALE=.23`，余量够吐火时升空 170 px 不出框），脚下画一滩自己的光（随亮度和离地高度变化）和一点淡淡的接触阴影；只有打盹、隐藏时才落到腿上，播放器用 `hover` 缓动在两种高度之间过渡，所以打盹是「降落」、唤醒是「起飞」。小动作都是飞行动作：歪一歪是侧倾着往一边滑，换脚是左右滑翔并压弯，伸懒腰是爬升一截再落回，识别中是左右巡弋。射激光时整盏灯升空约 70 px（`animation.flight`），腿收起、链条向后飘，扫完再降回来。
细节：冰晶上八个固定位置轮流闪星光（`effects.paint_glints`），周围九粒霜尘缓缓上飘（`paint_motes`，冰蓝 / 品红 / 白三色），两者都是动作进度的确定函数，待机循环照样走帧缓存。「!」「?」「z」用矿灯自己的冷色版本（`skins/lantern/*.png`，由布偶的手绘笔触重新上色：浅处冰白、重压处蓝紫，外面烘一圈蓝光），画时再垫一个随年龄呼吸的光晕；符号固定从矿灯右上角（画布 `SYMBOL_ANCHOR`，右晶簇上方）冒出，画在灯体变换之内，随灯一起倾斜和升空。

和布偶共用一套行为调度、拖动物理、帧缓存和气泡（`RigPlayer` 基类），动作对应关系：

| 事件 | 矿灯 |
|---|---|
| 待机 | 站在两条腿上，光芒三秒一次呼吸，链条和提手轻晃 |
| 识别中 | 亮核像探照灯一样在镜片里左右扫，带一道扫描线；腿和提手打拍子 |
| 悬停招呼 | 蹦一下、朝鼠标那侧瞥一眼、眨两下 |
| 识别失败（发火） | 眯眼、升空、晶簇哗啦作响。先蓄力：十四粒彗星状光点从四周被吸向镜片、紫环收缩、蓄力球胀大；放出一圈冲击波后射出**激光**（白核 + 冰蓝光晕 + 紫色外晕 + 品红/冰蓝异色边缘 + 沿束流动的能量条），在桌面上扫一个来回，落点有闪光、扩散环和十一粒头亮尾细、带下坠的飞溅火花（`effects._spark`），扫过处留下渐冷的灼痕，光束拖三道残影；扫完收束，降回原高度，并浮出「!」 |
| 识别成功 | 镜片炸开一圈小冲击波，吐出一颗带彗尾的光球，划弧落到身边地面；灯在空中绕两圈。鬼火是**蓝紫色**的四层噪声火舌（深蓝紫 → 蓝品红 → 冰蓝 → 白核），带发光的心、底部两小簇侧焰、地面光池、顶上冒紫烟、十颗拖尾火星由冰蓝冷却成紫，烧约 3.5 秒后缩小熄灭 |
| 冲突 / 异常 | 歪着身子，光一抽一抽地闪，浮出「?」 |
| 隐藏 / 打盹 | 光暗下去，半闭眼，提手耷拉；唤醒时猛地亮起来抖一抖 |
| 被拖动 | 像被拎着顶环：整体绕顶环摆动，两条腿晃荡，链条拖在后面；落地弹一下 |

激光和鬼火画在按钮之外：`EffectStage` 是一个穿透点击、不抢焦点、置顶的透明窗口，只在这两种动作期间出现在矿灯周围（约 2×激光长度，以地面点为锚，灯升空时窗口不动），动作结束就隐藏，不常驻。舞台内部用 Plus 合成叠加光晕，再由系统按 alpha 合成到桌面上，亮背景上也看得见。激光的扫射范围按屏幕剩余空间决定（贴着右边缘就只往左下扫），鬼火落在气泡的另一侧、屏幕有空的一侧。设置面板打开时不画舞台效果，避免盖住正在看的面板。所有效果都是动作进度的确定性函数，没有逐帧随机。

`out/lantern-demo/viewer/index.html`（由临时脚本生成，不入库）可逐帧查看每个动作和当帧的通道值。

## 性能

idle 呼吸与 doze 循环都是固定周期、无随机，各预渲染 30 帧缓存（按尺寸、DPI、透明度分组），只在帧序号变化时重绘：待机约 10 次/秒 blit，无重新渲染；打盹 10 fps。拖动、转头、淡出进行中按帧实时渲染，结束后回到缓存。事件动作仍以 25–40 fps 播放 2–4 秒。
