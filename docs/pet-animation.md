# 布偶伙伴

设置中的「布偶伙伴」开关控制布偶外观，关闭即恢复齿轮。拖动和点击操作不变，不影响识图、快捷键或叠图。提示直接显示在对话气泡中，没有角色名前缀。

布偶使用 `docs/images/logo.png` 的原始像素，运行时按多边形分成八层：头、身体、左右上臂、左右前臂、左右腿。原始 logo 不修改，不依赖外部动画软件或网络。

`mapmatching/pet.py` 的 `PARTS` 定义分层遮罩，`pose()` 定义关节角度。颈、肩、肘和髋有独立旋转中心；肘继承肩的变换。动作采用缓入、停留、缓出，结束回到原位。成功时双手收至胸口配爱心，失败时抬手挠头，交互时招手，隐藏时低头休息。

这是二维剪纸骨骼动画，不是三维模型或 Live2D 网格变形。logo 只有一个角度，背面和被遮挡部位没有独立素材；大幅转身和精细手指动作不在当前能力内。替换 logo 时须同步调整遮罩和关节位置。

动画只在事件触发时以 25 FPS 播放约 2.2 秒，待机不运行动画定时器。关闭布偶会立即停止动画；缺失 logo 时恢复齿轮。气泡不抢焦点、鼠标可穿透，保留原来的提示时长和屏幕边缘避让。
