# 小布偶桌宠化：现状与改进分析（2026-11-06，仅分析）

对象：`mapmatching/appearance/`（player / speech / events / skins/doll）与 `ui.py` 里的 `DraggableGear`。
判断依据：源码、本机实跑截图（idle / heart / angry / puzzled / 气泡 / 面板）。

## 一、现在有什么

- 一张 306×332 的布偶原图，运行时按 `rig.py` 的多边形拆成 8 层（头、躯干、左右上臂/前臂、左右腿），手臂沿长度连续弯曲、腿用贝塞尔弯曲，没有肘部折角。这套骨骼的质感已经相当好：灰白针脚布偶、纽扣眼、X 嘴，和游戏里的娃娃一脉相承，默认缩放 0.32 下线条干净。
- 动作：idle（呼吸+轻摆）、matching（左右摇）、heart/happy（抱胸+爱心）、angry（甩臂跺脚+「!」）、puzzled（挠头+「?」）、sleep（低头+「z」）、curious（招手）。效果符号是手绘 PNG，风格统一。
- 交互：悬停招手；按下播 heart；拖动移动；单击开设置（等一个双击间隔）；双击重新识别；**右键立即退出**；拖到右上角停 0.5 s 退出；托盘菜单。
- 反馈：`reaction(message)` 用关键字把提示文案映射成情绪；气泡 `SpeechBubble` 是深蓝渐变圆角框+1 px 亮边+尾巴，13 px 字，停留 1.2 s。
- 启动：`StartupPet` 用 matching 动作当加载指示。

## 二、离「完备桌宠」还差什么（按我认为的优先级）

### 1. 先把会伤到人的交互改掉（必做）
- **右键 = 立刻退出**（`ui.py:844-847`）。桌宠的右键惯例是菜单；识图中途一次误点就把助手关了，而且没有任何确认。改成右键菜单：重新识别 / 隐藏叠图 / 小游戏 / 设置 / 退出。退出放最后并和其他项隔开。
- 托盘菜单里「显示布偶」加了两次（`ui.py:1225-1226`），顺手删掉。
- 单击要等 300 ms 双击间隔才开面板，手感是"卡了一下"。建议：单击立即开面板（面板打开不是破坏性操作），双击仍重新识别——双击时先关掉刚打开的面板即可；或者把重新识别放进菜单，单击不再等待。
- 按下就播 heart、悬停就招手：布偶常驻在游戏右上角，鼠标路过就挥手会很吵。悬停反应加 8–10 s 冷却，面板打开时不反应，按下改为松开时才反应（拖动不算）。

### 2. 让它"活着"而不是循环呼吸（最影响观感）
- 现在 idle 只有一个 3 s 呼吸循环，看久了像屏保。加一个 1 Hz 的行为调度器：每 20–60 s 随机一个小动作（歪头、换脚站、抖一下耳朵、伸懒腰、看向鼠标方向、看向刚出现的气泡），带最小间隔和权重，matching/叠图期间不打断、省电模式下频率减半。小动作只用现有关节（头 ±15°、躯干倾斜、手臂抬放、腿前后）就够表达，不需要新图。
- **睡眠是状态，不是 2.2 s 的反应**：5 分钟无输入或游戏窗口不在前台超过 N 分钟 → 进入 sleep（呼吸变慢、低头、「z」缓慢冒），悬停或按键时伸个懒腰醒来。现在的 sleep 只在提示文案含"隐藏/关闭"时闪一下。
- 转头看气泡：气泡在哪一侧，头就向那侧转 8°，持续到气泡消失。只动 head pivot，成本几乎为零，但"它在说这句话"的感觉会强很多。

### 3. 拖动的物理感（第二影响观感）
- 现在拖动是窗口瞬移跟手，布偶像贴纸。建议：拖动时按鼠标速度让躯干反向倾斜、两条腿像钟摆一样滞后摆动、手臂随提起抬高（被"拎着头"的感觉，很符合布偶）；松手时一次轻微的下落+压扁回弹（`body_motion` 已有 squash）。全部由速度驱动关节角，不需要物理引擎。
- 加一个脚下的柔和椭圆阴影，随 y 弹跳缩放。单个椭圆，成本可忽略，但跳跃和落地立刻有"着地"感。现在所有动作都是悬空的。

### 4. 气泡与面板的视觉统一
- 气泡是通用深色 tooltip 的样子（渐变+亮边），和面板的雾面粉笔质感（`MistPanel` / `chalk_texture`）不是一家。改成 `chalk_texture('deep','rounded')` 的羽化边 + 手绘风尾巴，字体跟随「界面字体」设置，字号跟随 `font_size` 而不是写死 13 px。
- 气泡现在从布偶头顶偏右冒出且和爱心重叠（见实跑截图）。效果符号的生成区域和气泡位置要互相避让：有气泡时爱心偏向另一侧。
- 情绪映射的语气：匹配失败现在播 angry（甩臂跺脚），读起来像在冲玩家发火；失败是布偶自己没找到，用 puzzled/不好意思更合适；angry 留给异常、冲突、进程中断这类"出事了"。成功 heart、隐藏 sleep 保持。

### 5. 设置项（桌宠应有的边界）
- 大小（0.75–1.5×）、空闲 30 s 后半透明（悬停恢复）、「安静模式」（只保留结果反应，不做随机小动作）、位置锁定。这些都是常驻在游戏画面上的工具该给用户的控制权。
- 省电模式已有，行为调度器要读它。

### 6. 明确不建议做的
- 沿任务栏走路、翻身：现有素材只有一个正面视角，走路需要侧面/背面新图和新骨骼，投入大、和"悬浮助手"的定位冲突。想要"在屏幕边上待着"的感觉，更贴合布偶的是**挂在屏幕上边缘**（被线吊着、轻微晃）这种姿态，一张图就能做。
- 语音/音效：游戏本身有声音，桌宠出声只会打扰；最多给拖动一个极轻的布料声，可关。

## 三、建议的落地顺序

1. 交互修正：右键菜单、托盘重复项、单击不等待、悬停冷却（半天）。
2. 行为状态机 `PetBehavior`（Idle / Sleep / Matching / GameBackground / Reaction / Drag）+ 调度器 + 转头看气泡（一天）。
3. 拖动物理 + 落地回弹 + 脚下阴影（一天）。
4. 气泡重做 + 字体/字号跟随 + 情绪映射调整（半天）。
5. 设置项：大小 / 空闲透明 / 安静模式 / 位置锁定（半天）。

每一步都只增加事件驱动的动画，idle 仍走帧缓存；状态机把"什么时候可以动"集中管理，不会把这次省下的 CPU 再花回去。

## 四、实施记录（2026-11-06）

按用户要求：失败时的「发火」动作保留，情绪映射 `events.reaction` 未改；其余全部实现，行为说明见 `docs/pet-animation.md`。

- 交互：右键菜单（`DraggableGear.context_menu`）、托盘重复项删除、单击立即开面板、悬停冷却、松开时才抱一下。
- 行为：新模块 `appearance/behavior.py`（小动作调度、打盹/唤醒、空闲淡出、转头看气泡），新动作 `tilt / shift / stretch / doze / wake / land`。
- 拖动物理：`PetAnimation` 的 `begin_drag / drag_moved / end_drag` 与弹簧式四肢摆动、落地回弹；脚下阴影。
- 气泡：`SpeechBubble` 改为粉笔纹理与手绘尾巴，字号跟随界面字号；效果符号按气泡侧避让。
- 设置：布偶大小 / 空闲淡出 / 安静模式 / 锁定位置，持久化到 `ui_settings.json`。
- 验证：新增 `tests/test_pet_behavior.py`（10 项）；`test_manual_alignment` 的双击用例改为新语义；本机渲染各状态截图核对（阴影、气泡、避让、菜单、缩放）；实测待机 3 秒 0 次重新渲染、打盹稳定后 0 次、淡出进行中约 40 次一次性渲染。
- 未做：沿边走路、音效（见第二节第 6 点）。
