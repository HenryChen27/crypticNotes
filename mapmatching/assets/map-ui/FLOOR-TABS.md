# 楼层标签识别

`floor-1.png`、`floor-2.png` 来自本地 `examples/1/example.png` 的游戏数字轮廓，不使用系统字体替代。

PC 与 Android 共用 `src/floor_tabs.py`。在画面右上方较宽区域查找数字，校验 `1 2` 的间距、高度和排列；额外确认左侧数字与减号后识别 `-1 1 2`。比较各按钮背景亮度决定当前查看楼层。数字不清楚、高亮无差异或识别结果冲突时返回未知。

楼层结果限制当前匹配与已知地图重定位的候选楼层；未知时撤销限制。地图展开检测仍独立执行。标签只表示正在查看的楼层，不能单独确定地图身份、玩家位置或叠图变换。空白楼层不强行显示对齐叠图。

回归包含本地真实困难截图、手机未开地图截图，以及由真实数字轮廓构造的困难/噩梦按钮排列，覆盖缩放、黑边、轻微模糊和 JPEG 压缩。这些构造测试不等同于完整实机验证；聊天中新提供的噩梦视频截图尚未作为本地原图跑回归。
