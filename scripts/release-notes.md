# crypticNotes · 加页手记地图助手（Windows 便携版）

《第五人格》「加页手记」Windows 悬浮地图助手。

打开游戏地图后，助手根据屏幕截图识别地图和楼层，将完整路线图半透明叠加到游戏画面上，方便对照路线、探索和找路。

- 支持困难、噩梦单人和多人模式，内置 {{TOTAL}} 张地图：困难 {{HARD}} 张、噩梦单人 {{SOLO}} 张、噩梦多人 {{DUO}} 张。
- 多人地图未匹配时可尝试单人路线图，并提示「多人暂无专用路线」。
- 可调整叠图透明度和快捷键，支持本地截图测试、地图管理与手动录入新地图。
- 便携包自带运行环境，无需安装 Python。仅读取屏幕画面，不读取或修改游戏内存。

### 下载和使用

1. 下载下方 IdentityVMapAssistant-Windows-x64.zip，完整解压到普通文件夹。
2. 双击 crypticNotes.cmd 启动，点击悬浮齿轮选择难度和人数。
3. 将助手的地图快捷键设置为与游戏一致（默认 G），回到游戏打开地图。
4. 默认退格键隐藏或重新显示叠图，Esc 隐藏叠图。

需要桌面快捷方式时，运行 create-shortcut.cmd，把生成的快捷方式拖到桌面。请保留完整的程序文件夹；移动文件夹后重新生成快捷方式。

### 以后怎么更新

程序文件夹里带 `更新.cmd`，或在「使用偏好」点「检查更新」，即可检查版本、下载校验、自动替换并重启，不需要安装 Git。

**设置和识别记录保持原样**（存在 `%LOCALAPPDATA%\IdentityVMapAssistant`）。地图库是另一回事：更新把程序目录里的 `maps/` **整棵换成发布版那一份**，好让每个人拿到的地图与内置库一致 —— 自己录入的图和「管理地图」里的移除状态不会保留，想留着就在更新前把 `maps/` 复制到别处。

地图识别效果受探索范围、缩放和窗口布局影响，失败时可调整视野后重试。地图及路线素材来自凉哈皮，详细说明见仓库 README。
